## 📋 Overview

**ScanEat KSA** is a SaaS platform built for the Saudi restaurant industry, letting customers scan a QR code to browse a digital menu and place orders directly via **WhatsApp** — no app download required. Built and maintained by **[Codesudio](https://www.codesudio.com)**.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📱 **QR Digital Menu** | Contactless, mobile-friendly menu accessible via QR scan |
| 💬 **WhatsApp Ordering** | Orders sent directly to the restaurant's WhatsApp |
| 🍔 **Menu Management** | Restaurant owners manage items, categories, and pricing |
| ⚡ **Fast & Lightweight** | Built on Next.js for instant load times |
| 🗄️ **Supabase Backend** | Postgres database, auth, and storage out of the box |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pkmbilal/scaneatksa.git
cd scaneatksa
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result. 🎉

You can start editing the page by modifying `app/page.js` — the page auto-updates as you edit.
